# Web UI & API Automation Testing Framework

**A QA automation portfolio project built with Playwright, TypeScript, and GitHub Actions.**

## Project Overview

This project demonstrates automated software testing techniques for web applications and REST APIs using Playwright and TypeScript.

It includes functional UI testing, API testing, CRUD operations, negative testing, boundary value analysis, reusable test fixtures, and cross-browser testing.

The framework also includes automated test reporting, failure investigation tools, and a GitHub Actions CI pipeline.

**Project purpose:** To develop and demonstrate practical QA automation skills through hands-on testing exercises.

## Applications Under Test

**1. TodoMVC — Web UI Testing**

Practice application: https://demo.playwright.dev/todomvc/

Automated scenarios include adding, editing, completing, deleting, and filtering tasks, as well as rejecting empty task submissions.

**2. JSONPlaceholder — REST API Testing**

Practice API: https://jsonplaceholder.typicode.com/

Tests cover GET, POST, PUT, PATCH, DELETE, filtering, and HTTP error responses.

JSONPlaceholder simulates data modifications and does not permanently store created or updated resources.

**3. Local Task API — API Integration and Validation**

A Node.js practice API developed for this project.

Tests cover CRUD operations, saved-state verification, invalid inputs, boundary values, malformed JSON, and automated test-data cleanup.

The local API uses in-memory storage, which resets when the server restarts.

## Installation

**Prerequisites:** Node.js 24, npm, and Git.

Clone the repository:

`git clone https://github.com/ThuraAung6631503094/playwright-ui-api-automation.git`

Enter the project directory:

`cd playwright-ui-api-automation`

Install dependencies:

`npm ci`

Install Playwright browsers:

`npx playwright install`

On Windows PowerShell, use `npm.cmd` and `npx.cmd` if required.

## Running Tests

**Run the full Chromium test suite:**

`npx playwright test --project=chromium`

**Run the UI tests across all three browser engines:**

`npx playwright test tests/todo.spec.ts --project=chromium --project=firefox --project=webkit`

**Run API tests:**

`npx playwright test tests/api --project=chromium`

**Run tests with the browser visible:**

`npx playwright test tests/todo.spec.ts --project=chromium --headed`

**Open the HTML report:**

`npx playwright show-report`

The local practice API is started automatically by Playwright when needed.

## Continuous Integration

GitHub Actions automatically runs the automation framework on pushes and pull requests targeting the main or master branch. The workflow can also be triggered manually.

The CI workflow:

1. Checks out the repository.
2. Installs Node.js and project dependencies.
3. Installs Playwright browser dependencies.
4. Runs the full Chromium suite.
5. Runs the UI tests in Firefox and WebKit.
6. Uploads test reports and debugging artifacts.

## Scope and Limitations

This project is a learning and portfolio framework using public practice services and a custom local API.

The JSONPlaceholder endpoints simulate writes. The local API stores data in memory rather than a persistent production database. Automated tests cover the implemented scenarios and do not represent a complete security, performance, or accessibility assessment of a production application.
